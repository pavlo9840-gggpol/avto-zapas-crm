# АвтоЗапас

**Простий облік магазину шин, акумуляторів і мастил.**

АвтоЗапас — невелика веб-CRM для магазину автотоварів. Застосунок побудований
на Flask + SQLite.

## Функціонал

- Склад шин, акумуляторів, мастил та інших автотоварів зі спеціалізованими характеристиками товарів.
- Пошук, сортування, фільтри, низькі залишки, імпорт і експорт CSV.
- Зручна каса у стилі POS: швидкий пошук, кнопки категорій, картки товарів,
  кошик із лічильниками кількості, швидкий вибір суми готівки й розрахунок решти.
- Резерв товару на клієнта, зняття резерву й оформлення продажу із резерву.
- Клієнтська база з телефонами, примітками та історією покупок.
- Облікові записи адміністратора й продавця з розмежуванням прав.
- Чек, товарна накладна й розрахункова накладна з друком.
- Редаговані HTML-шаблони документів, реквізити магазину й поля-плейсхолдери
  у налаштуваннях адміністратора.
- Скасування продажу з поверненням товару на склад і записом у журналі.
- Звіти за поточний тиждень або місяць: виручка, продажі за категоріями
  та продавцями; прибуток доступний адміністраторам.
- Калькулятор порівняння розмірів шин і підбору акумулятора з наявності за
  типом техніки, ємністю, пусковим струмом, полярністю та корпусом.
- Перевірені магазином аналоги та заміни з типом зв'язку й приміткою продавцю.
  Зв'язки можна додавати вручну та переносити між системами через CSV; автоматичної
  перевірки сумісності з автомобілем немає.
- Окремі вкладки товарів для шин, акумуляторів, мастил та інших автотоварів;
  компактне розкривне меню з лічильниками товарів із низьким залишком.
- Публічна сторінка продукту з описом можливостей, скриншотами, донатом
  і миттєвим переходом у безпечне демо без реєстрації.

Перший вхід: логін `admin`, пароль `admin123` — **обов'язково змініть пароль
адміністратора одразу після входу**.

## Підтримка проєкту

На публічній сторінці продукту й сторінці входу є кнопка добровільної підтримки
проєкту: https://www.privat24.ua/send/k4gxk. Кнопка доступна в налаштуваннях
за замовчуванням; за потреби адресу можна перевизначити змінною `DONATION_URL`.
Доступ до CRM не залежить від донату.

Для локального запуску змінна задається перед стартом:

```bash
export DONATION_URL="ваше-перевірене-посилання-на-донат"
python app.py
```

На хостингу задайте `DONATION_URL` у змінних оточення WSGI/вебзастосунку.

## Чому саме PythonAnywhere, а не GitHub Pages

GitHub Pages вміє показувати лише готові HTML-сторінки — без сервера і без
бази даних. Ця програма зберігає склад, продажі та історію в базі даних,
тому їй потрібен справжній сервер (backend). **PythonAnywhere** — це
безкоштовний хостинг, який:

- не вимагає банківської картки;
- тримає сайт увімкненим постійно (на відміну від Render/Railway, де
  безкоштовний сервер «засинає» і скидає диск при кожному перезапуску —
  ваш склад просто зникав би);
- дозволяє зберігати файл бази даних (`stock.db`) назавжди.

## Крок 1. Реєстрація

Відкрийте **https://www.pythonanywhere.com/** → «Pricing & signup» →
виберіть безкоштовний план **Beginner** → зареєструйтесь (пошта + пароль,
без картки).

## Крок 2. Завантажити файли проєкту

У панелі PythonAnywhere відкрийте вкладку **Files**.

- Створіть папку, наприклад `warehouse`.
- Завантажте (кнопка **Upload a file**) усі файли з цього проєкту в неї,
  зберігаючи структуру:
  ```
  warehouse/
    app.py
    db.py
    constants.py
    tires_database.json
    requirements.txt
    templates/  (усі .html файли)
    static/     (style.css та папка brand_icons/)
  ```
  Найпростіше: заархівуйте папку `webapp` у `.zip`, завантажте архів через
  Upload a file, потім у вкладці **Consoles → Bash** розпакуйте його:
  ```bash
  cd ~/warehouse
  unzip webapp.zip
  ```

## Крок 3. Встановити залежності

У вкладці **Consoles** відкрийте **Bash** і виконайте:

```bash
cd ~/warehouse
pip install --user -r requirements.txt
```

## Крок 4. Створити веб-застосунок

1. Вкладка **Web** → **Add a new web app**.
2. Домен залишіть безкоштовний (`вашеIм'я.pythonanywhere.com`).
3. Виберіть **Manual configuration** → **Python 3.10** (або новішу з наявних).
4. У розділі **Code**:
   - **Source code**: `/home/вашеІм'я/warehouse`
   - Відкрийте посилання **WSGI configuration file** і замініть весь вміст на:
     ```python
     import sys
     path = '/home/вашеІм'я/warehouse'
     if path not in sys.path:
         sys.path.insert(0, path)

     from app import app as application
     ```
     (підставте своє ім'я користувача PythonAnywhere замість `вашеІм'я`)
5. У розділі **Static files** додайте:
   - URL: `/static/` → Directory: `/home/вашеІм'я/warehouse/static/`
   - За бажанням задайте `DONATION_URL` у WSGI-конфігурації, щоб увімкнути кнопку підтримки:
     ```python
     import os
     os.environ["DONATION_URL"] = "посилання-на-вашу-Банку"
     ```
6. Натисніть зелену кнопку **Reload**.

## Крок 5. Готово

Відкрийте `https://вашеІм'я.pythonanywhere.com` — тут буде сторінка продукту.
Натисніть «Тестова версія», щоб переглянути CRM із прикладами; або «Вхід», щоб
увійти у свій магазин. Початковий логін `admin`, пароль `admin123` — **обов'язково
поміняйте пароль адміністратора одразу після входу**.

Для демо створюється окрема база `demo.db` із вигаданими товарами та операціями.
Демонстраційна сесія відкриває цю базу лише для читання, а всі запити зі змінами
блокуються. Вона не використовує дані вашого магазину. За потреби задайте окремий
шлях для демо через `DEMO_DB_PATH`.

## Оновлення програми в майбутньому

Коли захочете щось змінити — завантажте оновлені файли через **Files**
(або `git pull`, якщо тримаєте код у репозиторії), потім знову натисніть
**Reload** на вкладці **Web**. База даних (`stock.db`) при цьому не
чіпається — весь склад і історія залишаються на місці.

## Резервна копія бази даних

Файл `stock.db` у папці проєкту — це вся ваша база (склад + історія).
Раз на деякий час варто завантажувати його собі на комп'ютер через
вкладку **Files** (кнопка download біля файлу) про всяк випадок.

## Для кількох магазинів

Поточна версія розрахована на окрему базу даних одного магазину. Для тестування
або використання кількома магазинами створюйте окрему інсталяцію та окрему базу
для кожного магазину. Не використовуйте одну спільну інсталяцію для різних
компаній: у цій версії немає розділення даних між компаніями.

## Локальний запуск (для перевірки на своєму компʼютері)

```bash
pip install -r requirements.txt
python app.py
```

Відкрити `http://localhost:5000` у браузері.

Перед публікацією в інтернеті налаштуйте HTTPS, змініть початковий пароль і
перевірте, що резервні копії бази даних створюються регулярно.
